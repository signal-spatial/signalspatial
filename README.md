# signalspatial

Website

## Logo

The mark is the Tennessee River Gorge below Signal Mountain, built as stacked relief terraces so the meander reads as an S. Earth tones sit on a dark ground, with a soft shadow under each step.

| File | Use |
| --- | --- |
| `brand/logo.svg` | Mark on the dark ground |
| `brand/logo-mark.svg` | Mark only, transparent background |
| `brand/logo-lockup.svg` | Mark and the signal_spatial wordmark |
| `brand/logo.png` | Raster of the mark |
| `brand/logo-lockup.png` | Raster of the lockup |

`scripts/build_logo.py` rebuilds these from public elevation tiles. It needs network access. Behind a Zscaler proxy, point Python at the local certificate bundle.
